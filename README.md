# Лабораторная работа 5 — интеграция, тестирование и запуск приложения

## Возможности

Приложение объединяет функции предыдущих лабораторных работ в настольном GUI на Flet:

- **Лаба 1:** запускает скрипт сбора изображений из Яндекс.Картинок и выводит его сообщения в интерфейс.
- **Лабы 2–3:** выбирает датасет `cat`/`dog`, показывает следующую картинку каждого класса в исходном датасете или созданной копии, формирует CSV-манифест с датой изменения в ISO 8601, создаёт копии `cat_0000.jpg` / `dog_0000.jpg` и копии со случайными номерами.
- **Лаба 4:** формирует DataFrame с классами и абсолютными путями; добавляет числовую метку, высоту, ширину, каналы и число пикселей; показывает `describe()`, число изображений по классам, статистики размеров, диаграмму баланса, фильтрацию по классу/размерам и гистограмму цветовых каналов.
- **Тестирование:** unit-тесты проверяют формирование аннотации, метаданные, фильтры, копирование, цветовые гистограммы и обработку ошибок.

## Требования

- Windows 10/11 и Python 3.12.
- Для кнопки веб-скрапинга репозиторий `lab01` должен располагаться рядом с `lab05` в общей папке. Ожидаемый путь: `NTSE/lab01/main.py`.
- Для самого скрапинга нужны доступ к интернету и установленный совместимый Chrome/Chromium с Selenium WebDriver. Сайт может менять разметку или ограничивать запросы, поэтому удалённый сбор нельзя гарантировать.

## Запуск в Windows

1. Склонируйте репозитории в одну папку:

   ```text
   NTSE/
   ├── lab01/
   └── lab05/
   ```

2. Откройте папку `lab05` и запустите `run.bat`. Скрипт создаст `.venv`, установит зависимости и откроет GUI.
3. Выберите корневую папку датасета, в которой находятся подпапки `cat` и `dog`. По умолчанию приложение ищет `../lab01/dataset`.
4. Чтобы начать анализ, нажмите «Выполнить анализ датасета». CSV-файлы сохраняются рядом с выбранной папкой датасета.

Установить окружение вручную можно командами:

```powershell
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

## Запуск тестов

```powershell
.venv\Scripts\activate
python -m pytest -v
```

Или запустите `run_tests.bat`. Тесты работают на временных миниатюрных изображениях и не требуют скачивать полный датасет или обращаться к Яндекс.Картинкам.

## Ограничения

- Датасет должен содержать каталоги классов `cat` и/или `dog`; изображения в корне датасета без папки класса не поддерживаются.
- Копии рекомендуется сохранять вне исходного датасета. Приложение запрещает размещать целевую папку внутри исходного набора.
- Сбор изображений зависит от сети, доступности сайта и поведения Selenium/браузера. Сбой скрапера не удаляет уже скачанные файлы.
- CSV с абсолютными путями привязан к текущему компьютеру; при переносе датасета эти пути могут потребовать обновления.
- Гистограмма строится для одного изображения выбранного класса за раз; для просмотра другого изображения нажмите кнопку ещё раз.

## Деплой

Для базового выполнения требований лабы подготовлен вариант `requirements.txt` + `run.bat`. GUI написан на Flet, поэтому для создания Windows EXE подходит команда `flet pack app.py --name NTSE_Lab05`. В текущем проекте скрапер запускается как соседний `lab01/main.py`, поэтому перед переносом только EXE надо отдельно решить, как включить скрипт скрапера, браузер/WebDriver и его зависимости; эта сборка пока не считается проверенной.
